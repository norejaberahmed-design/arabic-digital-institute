# Delivery Roadmap

## Phase 0 — Foundation
- Establish product, academic, privacy, and architecture decisions.
- Create repository conventions, quality gates, and contribution guidance.
- Confirm the Android-first development workflow.

## Phase 1 — Learning prototype
- Build navigation and learner onboarding.
- Implement a small, original Pre-A1 learning path.
- Support lesson playback, practice, answer feedback, and local progress.
- Use mock data and mock AI; no paid services.

## Phase 2 — Full-stack learner accounts
- Add authentication and learner profiles.
- Persist curriculum, attempts, and progress.
- Enforce server-side authorization and account isolation.
- Add integration and end-to-end coverage.

## Phase 3 — AI learning assistance
- Add provider-neutral tutor and conversation interfaces.
- Ground AI in approved lesson content.
- Add evaluation cases, safe fallbacks, and usage controls.
- Require approval before connecting any paid provider.

## Phase 4 — Instructor and administration
- Add content authoring, review, publication, and versioning.
- Add instructor workflows and learner support tools.
- Add audit trails for privileged actions.

## Phase 5 — Expansion and release readiness
- Expand levels and learning content.
- Improve speech practice and accessibility.
- Conduct security, privacy, performance, and usability reviews.
- Prepare deployment, backups, monitoring, and support operations.

## Release gates
A phase is not complete because a screen exists. Completion requires working behavior, verified persistence where applicable, tests, documented limitations, and evidence from the running application.
